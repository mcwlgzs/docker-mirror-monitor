API 自检面板

用于排查部署问题：健康检查、接口连通性、单源探测明细

1. 健康检查

调用 ?action=health。返回 503 表示数据目录不可写或 PHP 缺 curl 扩展， 页面上的检测结果将无法正常生成。

2. 全量探测

调用 ?action=check_all&force=1。这是首页使用的接口， 列出每个镜像源的 HTTP 状态码、握手耗时与失败原因。

3. 单源探测

调用 POST ?action=check_service，请求体 {"url":"..."}。 只接受服务列表中已登记的地址。

4. 原始响应

最近一次请求的原始 JSON，便于对照文档与上报问题。
